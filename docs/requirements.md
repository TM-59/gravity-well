# 要件

コード・テスト・bench の出力から起こした要件。数値は `src/`・`tests/`・`docs/narrative/` と遊べる門の実測による。

## 誰が・どんな場面で・何を楽しむか

- 軌道力学に興味がある人が、短い時間で「少しの噴射で行き先が大きく変わる」ことを手で確かめる。
- The Ice Run(5区間・1回およそ40 T)では、燃料という限られた資源で円軌道から円軌道へ移る判断と、
  内側の港に残る Ilse との別れの物語を一緒に体験する。
- 手動航行(月との会合)と Hohmann 遷移の実演は、物語なしで物理を観察するためのモード。

## 対応端末と入力

| 端末 | 入力 | 内容 |
|---|---|---|
| PC | キーボード | 手動航行 A/D(回転)・W(噴射)。The Ice Run W(Raise)・S(Lower)・M か Space(Match)。P で一時停止 |
| PC | マウス | 画面のボタンを押し続ける(Pointer Events) |
| スマートフォン | タッチのみ | 観測画面の「Start the ice run」、場面の選択肢、Raise/Lower/Match のボタンを押し続ける |

キーボードが無くても全モードを始めて、最後まで航行できる。保存機能・音・サーバー API は無い。

## 受入条件

### 物理と物語(`make test` / `make bench` / `make story-check`)

- 軌道・保存則・GIF 往復・手動航行の一致・Hohmann の2噴射(第1噴射 Δv=0.154706、Web 実演の最終半径 2.000127)。
- The Ice Run の場面順 dock → route → beacon → flare → ilse → silence → quay(12 seed)と両方の結末に届くこと。
- 物語の数値(`[mech]`)、重い場面の静けさ(`[quiet]` flare・ilse・silence)、2つの選択の得と損(`[choice]`)。
- `docs/narrative/` の行が Debian 13 の再実行とバイト一致すること。

### 遊べる門(iPhone 相当の縦 375×812・横 812×375・DPR 3・タッチのみ)

| 項目 | 条件 |
|---|---|
| ① 読み込み | canvas か本文が出る |
| ② タップで進行 | 最初の目標(The Ice Run の最初の会話を閉じて出港)に 25 秒以内 |
| ③ console error | 縦・横とも 0 |
| ④ 文字 | 描画される文字はすべて 14 CSS px 以上(canvas の目盛り・凡例・脚注を含む) |
| ⑤ タップ対象 | すべて 44×44 CSS px 以上 |
| ⑥ 縦横 | 横はみ出し 0、観測画面が画面の 50% 以上 |
| ⑦ 向き | 対象外。操作は軌道の増速・減速で、画面上の上下左右へ動かす操作ではない |

### 品質台帳

配信先の品質基準のうち、人の確認が要る項目(文字・ボタンの読みやすさの目視など)は門の ○ で代えない。
