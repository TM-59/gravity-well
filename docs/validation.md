## 操作と描画

ブラウザー検査は実際の WASM を読み込み、実キー/Pointer Events とブラウザーの時計で進める。
テスト用に物理状態を書き換える経路は無い。観測用の `orbitView.snapshot` は読み取り専用。

- 初期一時停止 → 手動起動 → 旋回後の船首と速度方向が異なる → 1.2秒噴射で Δv=0.024 → キーを離す → P で時間停止。
- 実演ボタン → 第1噴射 → 惰性で楕円を進む → 第2噴射 → 最終半径2.000127・合計Δv=0.284466・18.008 Tで停止 → Resetで時刻とΔvを0へ。
- 390×844の viewport → タッチから発生した Pointer Events で噴射 → touchCancel 後に噴射が止まる。
  水平はみ出し0、操作ボタンは44px以上。背景を隠す/フォーカスを失うと一時停止し、保持中の入力を解除する。
- 原画2枚を読み込めない条件でも C の時間が進み、観測を続けられる。

実画面で星・月・船・3本の参考円・航跡・速度矢印・単位・停止/噴射状態を目視確認した。
船は生成した透明スプライトで、旋回時にも縦横比を保つ。ヘッダーの装飾画に測定値は焼き込んでいない。
元の `src/orbit.c` は変更0。保存・乱数を新設していない。
